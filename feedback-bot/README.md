# Бот сбора отзывов (Джан / Hi Food)

Telegram-бот: клиент ставит оценки по 5 аспектам, прикрепляет фото и комментарий.
Отзывы пишутся в **Google Sheets** (или в `reviews.csv`, если Sheets не настроен).
Низкие оценки помечаются 🔴 и шлются админу приоритетным алертом.

## Запуск (3 минуты)

```bash
cd feedback-bot
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

`.env` уже создан с токеном. Минимум для старта — указать `ADMIN_CHAT_ID`
(узнать через [@userinfobot](https://t.me/userinfobot)), чтобы приходили уведомления.

> ⚠️ Токен был прислан в чат открытым текстом — перевыпустите его в @BotFather
> (`/revoke` → новый токен → вставить в `.env`).

## QR-коды на заведения

Бот понимает, откуда пришёл клиент, по deep-link — спрашивать заведение не нужно:

- Джан: `https://t.me/jan_food_feedback_bot?start=jan`
- Hi Food: `https://t.me/jan_food_feedback_bot?start=hifood`

Сгенерируйте QR на эти ссылки и положите на стол / в чек / на упаковку.
Без параметра бот покажет кнопки выбора заведения.

## Подключить Google Sheets (через Apps Script, ~2 минуты)

Без Google Cloud и JSON-ключей — только таблица и скрипт.

1. Создайте Google-таблицу.
2. **Расширения → Apps Script**, вставьте код из `google-apps-script.gs`, сохраните.
3. **Деплой → Новое развёртывание → Веб-приложение**: «Выполнять как: Я»,
   «Доступ: Все».
4. Скопируйте URL (заканчивается на `/exec`) и впишите в `.env`:
   `SHEETS_WEBHOOK_URL=...`. Перезапустите бота.

Заголовки колонок скрипт создаёт сам. Пока URL не указан — отзывы копятся
в `feedback-bot/reviews.csv`.

## Что собирается

Дата · Заведение · Имя · Телефон · TG username · TG ID ·
Общая · Вкус · Время доставки · Упаковка · Скорость · Комментарий · Фото(file_id) · 🔴 Важный

## Хостинг

Бот на polling — домен и вебхуки не нужны. Можно держать на любом VPS
(`nohup python bot.py &` или systemd) либо на free-tier Render/Railway.
