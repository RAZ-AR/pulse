# ayoo — лендинг «лояльность-тамагочи»

Единый источник правды по новому лендингу. Стиль: светлый неоморфизм + пиксельные
инвейдеры + LCD-экран + Press Start 2P. Аудитории: клиенты (главное) и бизнес.

---

## 1. Идея и позиционирование

**«Лояльность, которую можно погладить».**
Программа лояльности подаётся как тамагочи: ты заводишь питомца-инвейдера, и он
растёт каждый раз, когда ты выходишь в город (скан чека, чек-ин). Очки = еда.
Эволюция: Egg → Hatchling → Kid → Fox → Dragon → Phoenix.

Лендинг — это **сам тамагочи**: человек вылупляет и называет демо-питомца прямо на
странице, за 10 секунд понимает механику и забирает питомца в Telegram.

---

## 2. Аудитории, треки, навигация

Один URL. Верхняя панель:
- слева — пиксель-лого **ayoo**
- по центру — сегмент **[ Для тебя · Для бизнеса ]** (по умолчанию «Для тебя»)
- справа — языки **RU · EN · SR**

«Для тебя» = клиентский трек (живая игра, звезда лендинга).
«Для бизнеса» = бизнес-трек (конверсия в заявку).

---

## 3. 🔑 Крючок «забери питомца с собой»

Питомца, которого вылупили и назвали на лендинге, переносим в mini-app через
параметр запуска:

```
https://t.me/<bot>/app?startapp=pet-<KEY>-<name>
# пример: ...?startapp=pet-HATCHLING-Барсик
```

mini-app читает `startapp`, предзаполняет имя/стадию — пользователя встречает
**его** питомец. Лендинг → игра → установка ощущаются как одно действие. Это
главный конверсионный приём.

## 4. Клиентский трек (по умолчанию)

### 4.0 Hero — играбельный тамагочи
Состояния:
1. **Egg** — яйцо дрожит, подсказка «тапни 3 раза».
2. **Hatch** — после 3 тапов трескается и вылупляется Hatchling (вспышка пикселей).
3. **Name** — поле «назови питомца», имя сразу на LCD пиксельным шрифтом.
4. **Live** — питомец ходит по экрану, прыгает по тапу, «голодает» при простое.
5. **Grow (scroll-fed)** — по мере скролла страницы наполняется бар FED; на вехах
   питомец эволюционирует к следующему инвейдеру (демо-прогрессия).

Ряд кнопок под экраном (как на настоящем тамагочи): **Feed · Play · Stats** — каждая
даёт микро-анимацию и одну строку про реальную механику (Feed = скан чека,
Play = чек-ин, Stats = твои баллы).

CTA: **«Забери питомца в Telegram»** (deep link с именем/стадией) + QR.
Пасхалки: Konami-код, секретный инвейдер по 10 тапам в лого.

### 4.1 Как это работает — 3 шага
Пиксель-иконки: **Зайди в заведение → Отсканируй чек → Питомец вырос.**

### 4.2 Эволюция / коллекция
Лесенка из 5 инвейдеров с порогами очков:
`Hatchling 500 · Kid 1 500 · Fox 3 000 · Dragon 5 000 · Phoenix 8 000`.
Наведение/тап на каждого — он оживает. Сообщение: «докуда дорастёт твой».

### 4.3 Города соревнуются за тебя
Белград / Нови-Сад. Идея ayoo: заведения публично конкурируют ставкой баллов
(до 10×). Пиксель-карта с точками-заведениями.

### 4.4 Hi-score (соц-доказательство)
Аркадная таблица рекордов: начислено баллов · вылуплено питомцев · заведений.

### 4.5 Отзывы
Реплики в чат-пузырях / на LCD-экранчиках.

### 4.6 Финальный CTA
Большой QR + кнопка «Открыть в Telegram».

## 5. Бизнес-трек (переключатель)

### 5.0 Hero (swap)
«Заведения борются за гостей — а гости кормят питомцев у тебя».
Ценность: больше визитов, геймифицированная лояльность, без оборудования
(Telegram + QR).

### 5.1 3 шага для бизнеса
**Подключись → Поставь ставку баллов → Гости приходят.**

### 5.2 Калькулятор выгоды
Визиты × средний чек × частота → прирост. Пиксель-стиль.

### 5.3 Форма заявки
Поля: имя, заведение, город, контакт (Telegram/телефон). Отправка → бот/Sheets
(инфраструктура уже есть в проекте).

## 7. i18n
- Авто-язык: Сербия → SR, иначе по `navigator.language` (RU/EN). Выбор хранится в
  `localStorage`, переключатель сверху.
- Словари: `i18n.js` с объектами `ru/en/sr`, ключи = `data-i18n` атрибуты в HTML.
- SEO: `hreflang` + при необходимости пререндер 3 вариантов (`/`, `/en`, `/sr`).

## 8. Визуальная система
- Фон: `#E1E6EF` (как в mini-app). Карточки: белые, мягкая неоморфная тень.
- LCD-экран: `#dbdbdb` + точечная сетка, чёрный «ink» `#1A1208`.
- Палитра-акценты: orange `#ea5b0c`, teal `#1f71b8`, lilac `#B38BC8` (как в бренде).
- Шрифты: заголовки/текст — гротеск (Space Grotesk / Helvetica); акценты, цифры,
  UI питомца — **Press Start 2P**.
- Спрайты: те же инвейдеры (Egg/Hatchling/Kid/Fox/Dragon/Phoenix), 2 кадра.
- Движение: spring + смена кадров, без тяжёлых библиотек.

## 9. Технически (новый, статический)
Без фреймворка, как текущий лендинг:
```
landing/
  index.html        # разметка с data-i18n
  styles.css        # дизайн-система
  i18n.js           # словари ru/en/sr + переключатель
  pets.js           # спрайты-инвейдеры (строки) + рендер на <canvas>/DOM
  game.js           # hero-игра: egg→hatch→name→live→scroll-grow, кнопки, deep link
  business.js       # калькулятор + отправка формы
  app.js            # сегмент-переключатель треков, скролл-эффекты
```
Деплой: статикой на Vercel на корень `ayoo.space` (как сейчас, `framework:null`).
Спрайты переносим из `apps/mobile/src/components/AyooPet.tsx` (это просто строки).
